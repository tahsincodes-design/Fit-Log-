🏋️ FitLog — Workout Library & Gym Companion
FitLog is a dark, high-contrast gym companion app designed for tracking daily workouts with intent. Users can browse a full exercise library, view detailed execution guides for individual lifts, queue exercises into "Today's Plan", and bookmark workouts for future sessions.

🚀 Features
Interactive Exercise Library: Browse a structured grid of exercises displaying targeted muscle groups, equipment required, duration, calorie estimates, and ratings.

Dynamic Detail Pages: Access single exercise profiles (/workouts/[id]) with step-by-step instructions, difficulty levels, target set/rep ranges, and equipment specifications.

Today's Plan Tracker: Manage a daily workout queue with real-time aggregates tracking total exercises, duration (minutes), and total calories burned.

Saved Workouts Section: Save exercises for future planning in a dedicated tab accessible directly from navigation.

Dynamic List Sorting: Sort workouts inside your plan or saved list by duration, calorie burn, or user ratings.

Fully Responsive Dark UI: Gym-focused dark mode interface optimized for mobile, tablet, and desktop screens.

🛠️ Tech Stack
Framework: Next.js (App Router)

Language: TypeScript

Styling: Tailwind CSS & DaisyUI

Data Fetching: Server-side fetch with Next.js revalidation

Deployment: Vercel
